# 路线图

排序原则：**先做每天都用得上的，再补齐入口，最后打磨。** 每个里程碑结束时都是一个可以日常使用的版本。需求编号见 [requirements.md](requirements.md)。

## 开发期与日常使用

- 默认快捷键是 ⌥空格、双击 ⌥、⌥S（见 decisions.md D7），开发期与日常使用一致。Gloss 只在面板内处理文字，不改写其他应用的选区。

### M1 面板与对话核心

先做四项验证，任何一项不达标都先回到 tech-stack.md §九 的退路再继续：

1. 自绘输入框：中文拼音组字、候选窗位置、组字时的回车与 Esc。
2. 面板：不激活应用、拿到键盘、唤起延迟、隐藏后焦点回到原应用。
3. `ui/markdown`：中文、宽表格、长代码块、Claude Code 输出的视觉快照与流式手感。
4. ⌥空格：全局热键的注册、唤起与隐藏；自定义双击修饰键另验证输入监控权限与监听恢复。
