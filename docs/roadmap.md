# 路线图

排序原则：**先做每天都用得上的，再补齐辞达的入口，最后打磨和发布。** 每个里程碑结束时都是一个可以日常使用的版本。需求编号见 [requirements.md](requirements.md)。

## 与辞达的过渡

- M5 完成之前，两个应用同时运行：本项目的全局快捷键默认用 ⌃⌥A / ⌃⌥S / ⌃⌥D / ⌃⌥F，与辞达的 ⌥ 组合错开。macOS 会把同一个热键同时发给两个注册了它的应用，所以不能相同。
- M6 把默认快捷键换成 ⌥A / ⌥S / ⌥D / ⌥F，退出并卸载辞达。

### M1 面板与对话核心

先做三项验证，任何一项不达标都先回到 tech-stack.md §九 的退路再继续：

1. 自绘输入框：中文拼音组字、候选窗位置、组字时的回车与 Esc、系统听写（Fn Fn）。
2. 面板：不激活应用、拿到键盘、唤起延迟、隐藏后焦点回到原应用。
3. `ui/markdown`：中文、宽表格、长代码块、Claude Code 输出的视觉快照与流式手感。
