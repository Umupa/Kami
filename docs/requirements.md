# 需求

本文是需求的唯一来源：Kami 做什么、做成什么样。实现见 [architecture.md](architecture.md)，取舍的理由见 [decisions.md](decisions.md)。编号一经使用不再改动，删掉的需求留下空号。

## 一、定位与原则

**我自己的桌面 AI 工具箱。** 任何地方，一个快捷键，把手头的文字交给模型，用合适的提示词处理，结果可以直接用，也可以接着聊。面板里还有一个不接模型的笔记。

自用为主：功能按作者自己的 Mac 和使用习惯取舍。仓库公开，版本发布在 GitHub Releases，Kami 自己检查并安装更新。接入模型例外：配置提示词要让 Coding Agent 带任何人配好，无论手上是 API Key、Claude / ChatGPT 等订阅，还是本机模型。

- **入口比功能重要。** 唤起要比任何动效都快；带入选区、截图不抢焦点、剪贴板原样放回、不修改原应用的内容。
- **模式而不是聊天窗口。** 多数时候要的是「把这段文字变成那样」，对话是结果之后的延伸（问答模式除外）。
- **结果可以直接用。** 复制出来的东西不需要再手工清理。
- **设置给 agent 改。** 配置文件就是接口：字段有 schema 说明，改完热加载，错了不崩溃并指出错处。
- **不存东西。** 不保存会话和原文，日志里没有文字；笔记是唯一的例外，因为它是用户主动写下的。API Key 只在本机的配置文件里，不出现在任何输出中。
- **权限可选。** 没有辅助功能、输入监控或屏幕录制权限时降级可用，不强求。
- **原生、轻、快。** 单一 Go 二进制，不抢焦点，唤起即现，常驻内存小。

## 二、场景

| # | 场景 | 文字从哪来 | 期望的结果 | 模式 |
| --- | --- | --- | --- | --- |
| S1 | 读外文，翻译一段 | 选区 / 粘贴 | 译文，在面板里读或复制 | 翻译 |
| S2 | 润色一段文字 | 选区 / 粘贴 | 润色后的文字，复制回原处 | 润色 |
| S3 | 混乱文本，整理清楚 | 粘贴（聊天记录、网页、PDF 复制出的文字） | 结构清楚的 Markdown：标题、列表、表格 | 润色 |
| S4 | 读终端里 Claude Code 的英文输出 | 终端里的选区 | 中文译文；框线、硬换行由模型清理，代码、路径、命令原样 | 翻译 |
| S6 | 快速问一个问题 | 面板里输入 | 简短、准确的回答，可以追问 | 问答 |
| S7 | 读图片、视频字幕、远程桌面里的文字 | 屏幕截图，本机识别 | 识别出的文字进入面板，固定执行翻译 | 翻译 |

| S10 | 随手记一笔 | 面板里输入 | 自动保存的 Markdown 笔记 | 笔记 |

## 三、功能需求

### F1 面板

| ID | 需求 |
| --- | --- |
| F1.1 | 不激活应用的浮动面板：唤起后原应用保持前台，面板拿到键盘；浮在全屏应用之上，跨桌面空间 |
| F1.2 | 出现在鼠标所在屏幕，水平居中，顶边在可见高度 20%；按下即出现，不淡入 |
| F1.3 | 默认宽 800，高度随内容，顶边固定只向下生长，上限为可见高度 70%、最多 720pt。同一次会话里只长不缩：重新生成、切到结果更短或没有结果的模式都保持当前高度，多出的空间留在内容下方，控制条或追问栏始终贴着窗口底部；⌘N、带入新选区或截图开始新会话时才回到按内容计算；笔记的高度跟随笔记内容，切回模式时恢复原来的高度。结果变长时窗口一步长到新高度，不逐帧滑动、不闪烁，新文字仍按出字动画淡入；追问栏始终在窗口内。有结果时原文区默认最多 3 行；拖动原文下方的分隔线调整两者的占比，跟手不延迟，双击恢复默认；窗口变矮或结果出现时原文让位（至少为结果留出约 120pt），窗口重新变高时恢复拖出的高度；原文区至少容纳当前字号的一整行 |
| F1.4 | Esc、再按唤起键、点击面板外、切换应用时隐藏；隐藏不丢状态，进行中的请求继续，下次唤起原样出现 |
| F1.5 | 结构：原文栏 → 控制条（模式选择、执行按钮）→ 结果区（单轮结果或对话流）→ 追问输入框 |
| F1.6 | 每次唤起时原文栏拿到焦点，保留光标与选区，不自动全选 |
| F1.7 | 按住面板的非交互背景移动面板（模式条、追问栏周围、结果区两侧与内容下方的空白）；输入框、可选择的正文、按钮、链接、滚动条和原文分隔线保留各自的行为。拖动边缘调整大小；位置在同一块屏幕上保留，宽度与用户定下的高度在本次运行中保留，移动和调整只改用户动的那一维，不闪烁、不跳回；编辑原文不自动改回窗口高度。面板高度与内容不一致时（手动调过，或只长不缩留出了空白），控制条上出现「适应内容」按钮（⌥⌘0），把面板收放到内容当前的高度并回到按内容计算；按钮不随流式输出来回闪现。⌘⇧P 或模式条上的图钉固定面板：切到别的应用也不隐藏 |
| F1.8 | 配色来自 Omarchy 与 Flexoki，内置 18 套；默认 flexoki-light，`theme` 为 auto 时跟随系统（深色 flexoki-night、浅色 flexoki-light），可由 `/theme` 或 Operator 切换；配置里写着已移除的主题（everforest、last-horizon、miasma、nord、retro-82、ristretto）时改用默认主题，不报错；可自定义主题（F9.9）。背景默认毛玻璃，可改实色。字体固定为内置的 CaskaydiaCove Nerd Font，界面、正文和代码一致，缺少的中文与 emoji 字形由 macOS 补齐。⌘= ⌘- 调字号、⌘0 恢复，所有字号按比例缩放。小圆角、细边框、无阴影；按钮名称与快捷键放在悬停提示里，界面上常驻的按键提示只留不易发现的：控制条的「tab 模式」、追问栏的「⌘J 切换」、空白笔记的占位文字、笔记列表底栏，以及首次使用回复里的按键（F13）。截图层的外观见 F2.4 |

### F2 入口

一共三个全局入口，不做原处改进和原处翻译。

| ID | 需求 |
| --- | --- |
| F2.1 | **⌥空格显示 / 隐藏面板**：默认 `option+space`，不读选区，面板原样出现；默认入口不需要输入监控权限 |
| F2.2 | **双击 ⌥ 带入选区**：默认 `double-option`，第二次松开时触发，中间按了别的键就作废；唤起前读取选区，与上次带入的不同则开始新会话、替换原文、用默认模式立即执行；相同或没有选区时原样出现 |
| F2.3 | 读选区先用辅助功能（`kAXSelectedText`，最多 150ms），读不到时模拟一次 ⌘C（最多再等 500ms，兼容终端异步读取选区），等待剪贴板变化且文本写完后再读取；剪贴板每一项每一种类型原样放回并标记为临时内容，成功后不再回滚后续复制；排除编辑器无选区时的整行复制；密码框、安全输入、前台是自己时不复制 |
| F2.4 | **⌥S 截图**：默认 `option+s`。冻结鼠标所在整块屏幕的原生像素，不含指针；框选窗口无边框、覆盖整屏，不叠加原生标题栏；冻结画面上 120ms 淡入纸雾（亮屏 #F7F6F1 / 72%，暗屏 #1B1A17 / 45%），提示胶囊顶边位于可见高度 20%，使用系统界面字体；拖出 8pt 圆角选区，亮屏双层阴影，暗屏白色细边，选区碰到提示时提示淡出；Esc、右键或任一边不足 4pt 的点击取消且不显示面板，普通失焦不取消；松手后本机识别中英文，同一行从左到右、自然折行接回段落，保留空行、列表与提前结束的行，清空旧会话与追问，固定执行翻译；识别出的文字总是材料，不解析成命令；无文字时清空原文与旧结果，仅提示「截图里没有识别到文字」，不发请求；采集、框选和识别期间其他入口等待，本次结束后才恢复 |
| F2.5 | 三个快捷键都可以在配置里修改或清除，每个都可以是组合键或双击修饰键，彼此不能相同 |
| F2.6 | 首次配好模型后，在「已连接」回复里逐项授权（F13.4）；之后缺权限时，在用到它的那一刻请求并在面板里说明（双击修饰键需要输入监控：已经有模型时启动就请求，因为双击要先被监听到才谈得上「用到」；还没有模型时启动不请求；带入选区需要辅助功能，截图需要屏幕录制，不显示翻译面板）。每项权限在一次运行中第一次请求时只调用系统的请求，由 macOS 弹出提示并把 Kami 加进系统设置的列表；再次请求时才打开对应的系统设置页——两者同时发生时，设置页会在 Kami 加入列表之前打开，看不到 Kami；说明里提示：开关已打开却无效时，从列表移除 Kami 再重新添加；面板总能从菜单栏打开 |
| F2.7 | 菜单栏图标是单色的小狐剪影，适应系统深浅色，忙碌时右下角显示圆点。菜单包含：显示面板、截图识别（两项都标出当前的组合键）、「显示 Dock 图标／隐藏 Dock 图标」（F11.1）、「复制提示词」（随时复制交给 Coding Agent 的配置提示词，Kami 用着有问题时也能交给 Agent 检查）、「检查更新…」（右侧灰字是当前版本，F14.7）、重新启动（输入监控和屏幕录制授权后要重启才生效）、退出。顶部是状态行，让用户一眼看出 Kami 能不能用：SF Symbol 加当前模型名——未连接模型（虚线圆）、正在检查（点线圆）、连接正常（绿色对勾）、缺少 API Key / 连不上 / 请求被拒绝 / 安全连接失败（红色叉）、响应超时 / 请求受限（橙色感叹号）；模型配好或改动时（含启动）发一次与 `check` 相同的最小请求确认连接，之后以用户每次请求的结果为准（超长不算）；配置出错时下面再加一行「config.json 有 N 处错误」（橙色三角）；点击状态行打开面板；服务地址与错误详情在悬停提示里 |

### F3 模式

模式就是提示词预设，没有各自的特殊逻辑。

| ID | 需求 |
| --- | --- |
| F3.1 | 模式由四个属性定义：名字、提示词、输入语义（材料 / 指令）、输出格式（Markdown / 纯文本）；所有模式用同一个模型（F6.2） |
| F3.2 | 内置三个模式：翻译、润色、问答（定义见 §四）；它们只是配置的默认值。翻译的标签只在它是当前模式时显示方向（如「翻译 → English」）。配置里写着已移除的 `prompt`（提示词梳理）而没有自己的提示词时，忽略这一项，不报错 |
| F3.3 | 控制条上按顺序显示模式，Tab / ⇧Tab 循环切换，⏎ 执行当前模式；模式过多时横向滚动。原文栏输入 `/` 列出命令（Operator、主题、各模式、笔记与检查更新），↑↓ 选择、Tab 或 ⏎ 确定、Esc 关闭 |
| F3.4 | 模式列表在配置文件里：可以增删、改提示词、排序，第一项是默认模式；内置模式可以恢复默认 |
| F3.5 | 翻译：其他语言译成「我的语言」，原文是我的语言时译成「外语」；方向由模型按提示词判断，本机不做语言识别 |
| F3.6 | 用 Operator 查看模式与提示词，用一句话增删和修改 |

### F4 对话

| ID | 需求 |
| --- | --- |
| F4.1 | 任何模式的结果之后都能追问；追问的内容作为指令，带着此前的全部轮次发给模型 |
| F4.2 | 问答模式以对话开始：原文栏就是第一句提问 |
| F4.3 | 对话流里每一轮可以单独复制；最后一轮可以重新生成 |
| F4.4 | ⌘N 开始新会话，清空原文和对话；带入新选区或截图也开始新会话 |
| F4.5 | 会话只在内存里，只保留当前一个，应用退出即消失；不写任何会话记录 |
| F4.6 | 上下文超过模型窗口时，保留第一轮和最近几轮，丢弃中间轮次，并在对话流里标出 |
| F4.8 | ⌘J 在原文和追问之间切换焦点；回到原文时光标在文字末尾 |

### F5 结果呈现与复制

| ID | 需求 |
| --- | --- |
| F5.1 | 结果按 GFM 渲染：标题、列表、任务列表、表格、代码块（语法高亮）、引用、链接、删除线、公式 |
| F5.2 | 流式渲染：网络的突发到达被平滑成匀速出字并淡入；半截语法按最终样式显示；已完成的块不再变化 |
| F5.3 | 对话跟随末尾：生成中最新内容保持在视野里并平滑滚动；用户上滚即停止跟随，滚回底部恢复；离开底部时，结果区底部居中显示「↓」回到底部按钮；追问总是回到底部。内容没有溢出时固定在顶部：请求开始、首段到达、出字、重新执行或重新生成都不让已有文字上下跳动；历史回复的操作栏悬停时才显示，显隐不改变正文位置 |
| F5.4 | 生成中显示等待光标；完成、停止、失败在结果标题上有明确状态 |
| F5.5 | 复制：⌘C 复制 Markdown 原文；复制菜单里有「纯文本」；代码块单独有复制按钮 |
| F5.6 | 复制为富文本（HTML 与纯文本），粘到飞书、Notion 时表格仍是表格 |
| F5.7 | 每个模式各有一份结果：切换模式显示该模式自己的结果（没有就空着），切走时仍在生成的继续生成；原文改变后，各模式已有的结果都标上「原文已改」，不自动请求。新会话（⌘N、带入选区或截图）清空全部 |

| ID | 需求 |

### F7 失败与恢复

| ID | 需求 |
| --- | --- |
| F7.1 | 失败不弹窗，保留已输出文字，在结果后用两行说明给出下一步；按用户要做的事分类：超时、断网、服务商限制、安全连接、配置错误、未知 |
| F7.2 | 配置类错误的说明是「⌘C 复制提示词」：按 ⌘C 或点这一行复制配置提示词（与首次使用的是同一份，Agent 用 `check --verbose` 重现这次失败）；其他给「重试 ⏎」 |
| F7.3 | 服务商明确返回长度超限时自动分段（段落 → 句子 → 空白 → 字符），成功的片段不重发，按顺序拼回；对话模式下先裁剪上下文再分段 |

### F8 配置接口

设置的主要使用者是 agent。配置文件就是接口，命令行只补文件做不到的事。

| ID | 需求 |
| --- | --- |
| F8.1 | `config.json` 是全部设置的唯一来源：模型、模式、快捷键、我的语言、外语、开机启动、Dock 显示、笔记目录、主题与外观；旁边有 `config.schema.json`（JSON Schema），每个字段写清含义、取值、默认值和示例 |
| F8.2 | 热加载：应用监听配置文件，改完立即生效，不需要重启；进行中的请求不受影响 |
| F8.3 | 模型配置错误（包括旧的 `models`、`defaultModel`）不阻断主题、字号、背景、快捷键等其他有效设置的加载、保存和重启后恢复；模型沿用上次有效值，没有则保持未配置。模型字段在其他设置保存时原样保留，错误仍在菜单栏提示，`check` 仍严格报错；JSON 语法或其他设置不合法时沿用上一份可用配置，任何配置内容都不导致崩溃 |
| F8.5 | `check`：校验配置，再用模型真的请求一次，报告是否可用、耗时和回复；`--verbose` 列出实际请求与响应，Key 在任何输出里都打码；`--json` 给 agent 稳定的结构 |
| F8.6 | 配置提示词：交给 Coding Agent 的说明，只有一份，不随配置状态变化（D24），语气友好、以用户的口吻写：可执行文件、配置文件与 schema 的路径；要求 Agent 用大白话、一次只问一个问题、给编号选项、需要用户动手时说明并等待；先读 schema 和配置再运行 `check`，按结果走（没有模型 → 从头配置；配置不合法 → 直接修；缺 Key → 请用户复制；请求失败 → `check --verbose` 找原因；已可用 → 问想调整什么）；从头配置时先查看本机有没有 magpie 网关与 Ollama / LM Studio，再问用户手上有哪种：API Key、订阅（经 [magpie](https://github.com/yetone/magpie) 网关 `127.0.0.1:3425` 使用，征得同意再安装，提醒额度、需保持运行与服务商条款）、本机模型、都没有（推荐两三个）；选模型优先便宜、快、不带思考的（DeepSeek、GPT 的 mini / nano、`gpt6-luna` 等），不默认选 Claude Haiku 这类单价更高的；不变的规矩：只改 `model`、关掉思考、Key 不经过对话（用户复制后由 Agent 用 `pbpaste` 写入）、改完运行 `check`；最后一两句话说明结果，告诉用户回到 Kami 按 ⏎ 试一次。不含 Key 与任何配置值；由首次使用、配置类失败、菜单栏与 Operator 给出 |
| F8.7 | 命令行与应用是同一个可执行文件 |

### F9 Operator

| F12.5 | 自动保存：停止输入约 500ms 后、切出笔记或隐藏面板时写入，没有保存按钮；写入是原子的，失败时在控制条上提示，编辑区内容不丢 |
| F12.6 | 多张笔记：第一行（去掉开头的 Markdown 标记）就是标题；⌘N 或控制条上的「新建」新建一张空白笔记（列表里也可以输入标题新建），当前笔记已经是空的时停在这张，不再多建 |

| F12.10 | 每张笔记是一个 `.md` 文件，文件名是创建时间（如 `2026-10-19-143012.md`），改标题不重命名；默认目录 `~/Library/Application Support/Kami/notes/`，可由配置的 `notesDir` 改到任意目录，不存在时创建 |
| F12.11 | 文件被外部修改（同步、其他编辑器）时，下次显示或切换到它时重新读取，以磁盘上的为准，不做合并 |
| F12.12 | 日志只记笔记的事件与耗时，不记文件名以外的任何内容 |
| F12.13 | 列表里输入即按标题与正文过滤，命中的字高亮；只命中正文时在标题下显示命中的那一行。最后一行总是新建：加号后面是搜索词，没有匹配时它是选中项，⏎ 新建一张以搜索词为第一行的笔记 |
| F12.14 | ⌘[ / ⌘] 不打开列表，按最近编辑的顺序切到上一张、下一张；连续切换时顺序固定，不因切换本身改变 |

### F13 首次使用

没有模型时，Kami 用一段自己的回复带用户把配置提示词交给 Coding Agent。引导就是结果区里的一次普通回复，和模型的回复同样排版、同样出字，不另做组件（D21）。

| ID | 需求 |
| --- | --- |
| F13.1 | 启动时还没有模型就直接显示面板；首次使用与授权步骤（F13.4）期间失去焦点时面板不隐藏，用户切到终端把提示词交给 Coding Agent 时它还在，但不置顶（不同于 ⌘⇧P 固定），系统设置与系统授权弹窗能盖在它上面；面板在后面时 ⌥空格把它提到前面；授权步骤结束后恢复失焦即隐藏。没有模型时，每次唤起或 ⌘N 之后，结果区是 Kami 自己的一段回复：一句说明，加上配置提示词的代码块；像模型的回复一样流式出字，用同样的 Markdown 排版和底栏；代码块自动换行，不横向滚动；从顶部读起，不跟随末尾 |
| F13.2 | 没有模型时 ⏎、`/operator`、底栏的复制按钮与 ⌘C 都复制配置提示词本身；原文保留，配好后一次 ⏎ 就能执行；执行按钮与追问栏隐去；`/theme` 照常可用；双击 ⌥ 带入的选区和截图识别的文字只放进原文，不执行、不复制。复制只由用户触发，不自动写剪贴板 |
| F13.3 | `config.json` 不合法时，这段回复先列出出错的字段与原因，后面是同一份配置提示词 |
| F13.4 | 本次运行中模型从无到有时（热加载读到），Kami 接着回复「已连接 <模型名>（<服务地址>）」和打开面板的快捷键，下一步就是授权：先说「接下来授予以下权限，以使用完整功能：」，再以任务列表列出各入口需要的权限（各带用途与快捷键）；控制条的执行按钮随步骤改名为「授权」「重新启动」；点一次「授权」或按 ⏎ 就完成请求：先弹出系统提示（这一步把 Kami 加进系统设置的列表），约 1.5 秒后打开对应的系统设置页；回复末行说明点哪个按钮、在哪里打开开关；面板每秒读一次权限，授权后勾选实时更新；全部授权后，若输入监控或屏幕录制要重启才生效，⏎ 重新启动 Kami。顺序是辅助功能、输入监控、屏幕录制：辅助功能立即生效，后两项常让 macOS 提示「退出并重新打开」，所以授权步骤跨重启保留——未完成时下次启动直接显示面板，接着列出剩余的权限；全部生效时，回复变为「准备就绪」：已连接的模型，一张按键表（三个入口的快捷键、Tab 切换模式、⏎ 执行与追问、/ 命令与 /operator），以及「输入或粘贴一段文字，按 ⏎ 试一次」；重启后接着显示的也是它。用户开始使用 Kami（原文有字时 ⏎ 按当前模式处理，剩下的权限在用到时再请求）时步骤同样结束。面板不自己弹出（它会拿走键盘），下次唤起时看到 |

## 四、内置模式

| 模式 | 输入语义 | 提示词要点 | 输出 |
| --- | --- | --- | --- |
| 翻译 | 材料 | 互译：其他语言 → 我的语言；我的语言 → 外语。润色译文使其自然地道，杂乱或密集文本自动整理成清晰格式（段落、列表、表格）。原文是终端输出或截图识别的文字时，先去掉框线、控制符号和断行；代码、路径、命令、标识符、品牌名原样 | 跟随原文：原文是 Markdown 时保留结构，否则纯文本 |
| 润色 | 材料 | 保持原文语言，润色用词、语法、语气，不改意思；内容杂乱时（聊天记录、网页或 PDF 复制的文字）整理成标题、列表、表格，不增删事实 | 跟随原文 |
| 问答 | 指令 | 直接回答，先给结论，简短；不确定时说明 | Markdown |

输出语言：翻译按上表；润色跟随原文；问答跟随输入语言。都可以在提示词里改。

## 五、非功能需求

| 类别 | 指标 |
| --- | --- |
| 唤起 | 按下快捷键到面板可见 ≤ 50ms；带入选区时辅助功能读取预算 150ms，复制兜底最多再等 500ms；文字写入后立即返回，不固定等待到上限 |
| 首字 | 收到第一个 token 到它开始显示，本机开销 ≤ 2 帧 |
| 流式 | 120Hz 屏幕上不掉帧；每个 token 的渲染开销不随回复长度增长；60,000 字的回复仍然流畅 |
| 输入 | 原文栏粘贴 100 万字不卡顿；中文输入法组字期间回车、Esc、Tab 交给输入法 |
| 资源 | 空闲时不跑定时器和刷新回调（截图结束 30 秒后的一次性内存回收除外，见 D30）；常驻内存目标 ≤ 100MB；空闲 CPU 为 0 |
| 体积 | 应用包目标 ≤ 50MB |
| 系统 | macOS 15.2 及以上，Apple Silicon 与 Intel，两种架构分别发布 |
| 稳定性 | 网络、权限、系统 API、配置文件的失败都不导致崩溃；任何读取都有超时 |

## 七、不做的事

- 不直接改写其他应用中的选区；润色和翻译都在面板内完成，由用户复制结果。
- 不做听写和语音识别。
- 不做完整的命令行，只有 `check`；不做 MCP 服务或其他常驻的 agent 接口。
- 不保存会话历史，不做会话列表和搜索。
- 不做多个模型，也不按模式指定模型（D22）；不提供第三方应用的模型配置导入。
- 笔记不接模型：不把面板的结果存成笔记，不对笔记做 AI 改写；不做文件夹、标签和置顶。
- 不做 Windows、Linux 版本；不做 Developer ID 签名与公证（暂用自签名，D27）。
- 不内置模型、不做账号体系和云同步。
- 不做文件、图片附件的对话（截图只取文字）。
