# 需求

本文是需求的唯一来源。目标与最终效果见 [vision.md](vision.md)，实现方式见 [architecture.md](architecture.md)。Kami 的行为约定在本文完整定义，不依赖其他应用的规范。

## 一、优先级

| 级别 | 含义 |
| --- | --- |
| **P0** | 一期日常使用所必需 |
| **P1** | 明显提升体验，紧随 P0 完成 |
| **P2** | 以后再做，或等待定问题有了答案 |

## 二、场景

| # | 场景 | 文字从哪来 | 期望的结果 | 模式 |
| --- | --- | --- | --- | --- |
| S1 | 读外文，翻译一段 | 选区 / 粘贴 | 译文，在面板里读或复制 | 翻译 |
| S2 | 润色一段文字 | 选区 / 粘贴 | 润色后的文字，复制回原处 | 润色 |
| S3 | 混乱文本，整理清楚 | 粘贴（聊天记录、网页、PDF 复制出的文字） | 结构清楚的 Markdown：标题、列表、表格 | 润色 |
| S4 | 读终端里 Claude Code 的英文输出 | 终端里的选区 | 中文译文；框线、硬换行由模型清理，代码、路径、命令原样 | 翻译 |
| S5 | 把模糊的需求梳理成提示词 | 面板里输入 | 结构化提示词（背景、目标、约束、验收） | 提示词梳理 |
| S6 | 快速问一个问题 | 面板里输入 | 简短、准确的回答，可以追问 | 问答 |
| S7 | 读图片、视频字幕、远程桌面里的文字 | 屏幕截图，本机识别 | 识别出的文字进入面板，固定执行翻译 | 翻译 |
| S8 | 对任何结果不满意 | 上一轮结果 | 追问调整：「再短一点」「换个语气」「表格加一列」 | 任何模式 |
| S9 | 调整设置、加一个模式 | 交给 agent | agent 改配置文件，应用立即生效，agent 能自己检查 | — |

## 三、功能需求

### F1 面板

| ID | 需求 | 级别 |
| --- | --- | --- |
| F1.1 | 不激活应用的浮动面板：唤起后原应用保持前台，面板拿到键盘；浮在全屏应用之上，跨桌面空间 | P0 |
| F1.2 | 出现在鼠标所在屏幕，水平居中，顶边在可见高度 20%；按下即出现，不淡入 | P0 |
| F1.3 | 默认宽 800，高度随内容，顶边固定只向下生长，上限为可见高度 70%；窗口在内容绘制的那一帧就请求新高度，下一帧跟上，收回时面板背景铺到窗口底部、不露空隙，菜单等新内容在窗口容得下之后整块出现。有结果时原文区默认最多 3 行，把空间留给结果；拖动原文下方的分隔线调整两者的占比，跟手不延迟，双击恢复默认 | P0 |
| F1.4 | Esc、再按唤起键、点击面板外、切换应用时隐藏；隐藏不丢状态，进行中的请求继续，下次唤起原样出现 | P0 |
| F1.5 | 结构：原文栏 → 控制条（模式选择、执行按钮）→ 结果区（单轮结果或对话流）→ 追问输入框 | P0 |
| F1.6 | 每次唤起时原文栏拿到焦点，保留光标与选区，不自动全选 | P0 |
| F1.7 | 按住模式条移动面板，拖动边缘调整大小；位置在同一块屏幕上保留，宽度与用户定下的高度在本次运行中保留；移动和调整只改用户动的那一维，不闪烁、不跳回。⌘⇧P 或模式条上的图钉固定面板：切到别的应用也不隐藏 | P0 |
| F1.8 | 配色来自 Omarchy 与 Flexoki，内置 18 套；默认 flexoki-night，`theme` 为 auto 时跟随系统（深色 flexoki-night、浅色 flexoki-light），可由 `/theme` 或 Operator 切换；配置里写着已移除的主题时改用默认主题，不报错；可自定义主题（F9.9）；背景默认毛玻璃（macOS 的模糊材质透出桌面），可改实色；字体固定为应用内置的 CaskaydiaCove Nerd Font，界面、正文和代码一致，不提供字体切换或替代字体链；字体缺少的中文与 emoji 字形由 macOS 补齐；⌘= ⌘- 调字号、⌘0 恢复，所有字号按比例缩放；小圆角、细边框、无阴影；截图层使用 F2.4 的纸雾、阴影与系统界面字体提示胶囊 | P1 |

### F2 入口

一共三个全局入口，不做原处改进和原处翻译。

| ID | 需求 | 级别 |
| --- | --- | --- |
| F2.1 | **⌥空格显示 / 隐藏面板**：默认 `option+space`，不读选区，面板原样出现；默认入口不需要输入监控权限 | P0 |
| F2.2 | **双击 ⌥ 带入选区**：默认 `double-option`，第二次松开时触发，中间按了别的键就作废；唤起前读取选区，与上次带入的不同则开始新会话、替换原文、用默认模式立即执行；相同或没有选区时原样出现 | P0 |
| F2.3 | 读选区先用辅助功能（`kAXSelectedText`，最多 150ms），读不到时模拟一次 ⌘C（最多再等 50ms），剪贴板每一项每一种类型原样放回并标记为临时内容；排除编辑器无选区时的整行复制；密码框、安全输入、前台是自己时不复制 | P0 |
| F2.4 | **⌥S 截图**：默认 `option+s`；截图体验对齐 cida：按显示器 ID 冻结鼠标所在整块屏幕的原生像素，不含指针；框选窗口真正无边框，覆盖整屏且不叠加原生标题栏；冻结画面上 120ms 淡入纸雾（亮屏 #F7F6F1 / 72%，暗屏 #1B1A17 / 45%），提示胶囊顶边位于可见高度 20%；拖出 8pt 圆角纸片选区，亮屏双层阴影，暗屏白色细边，选区碰到提示时提示淡出；Esc、右键或任一边不足 4pt 的点击取消且不显示面板；松手后本机识别中英文并恢复段落，清空旧会话与追问，固定执行翻译；无文字时清空原文与旧结果，仅提示「截图里没有识别到文字」，不发请求；采集、框选和识别期间其他入口等待，本次结束后才恢复 | P0 |
| F2.5 | 三个快捷键都可以在配置里修改或清除，每个都可以是组合键或双击修饰键，彼此不能相同 | P0 |
| F2.6 | 功能缺权限时，在用到它的那一刻请求授权并在面板里说明（双击修饰键需要输入监控，启动时就请求，因为双击要先被监听到才谈得上「用到」；带入选区需要辅助功能，截图需要屏幕录制，申请未获准时直接打开对应系统设置页，不显示翻译面板）；说明里提示：开关已打开却无效时，从列表移除 Kami 再重新添加；面板总能从菜单栏打开 | P0 |
| F2.7 | 菜单栏图标只是入口：显示面板、截图识别、重新启动（输入监控和屏幕录制授权后要重启才生效）、退出；配置出错时顶部有一行提示；请求进行中图标有活动状态 | P0 |
| F2.8 | 每个模式可以绑定自己的全局快捷键 | P2 |

### F3 模式

模式就是提示词预设，没有各自的特殊逻辑。

| ID | 需求 | 级别 |
| --- | --- | --- |
| F3.1 | 模式由五个属性定义：名字、提示词、输入语义（材料 / 指令）、输出格式（Markdown / 纯文本）、默认模型 | P0 |
| F3.2 | 内置四个模式：翻译、润色、提示词梳理、问答（定义见 §四）；它们只是配置的默认值。翻译的标签只在它是当前模式时显示方向（如「翻译 → English」） | P0 |
| F3.3 | 控制条上按顺序显示模式，Tab / ⇧Tab 循环切换，⏎ 执行当前模式；模式过多时横向滚动。原文栏输入 `/` 列出命令（Operator 与各模式），↑↓ 选择、Tab 或 ⏎ 确定、Esc 关闭 | P0 |
| F3.4 | 模式列表在配置文件里：可以增删、改提示词、排序，第一项是默认模式；内置模式可以恢复默认 | P0 |
| F3.5 | 翻译：其他语言译成「我的语言」，原文是我的语言时译成「外语」；方向由模型按提示词判断，本机不做语言识别。控制条上显示「翻译成 外语」 | P0 |
| F3.6 | 用 Operator 查看模式及其模型与提示词，用一句话增删和修改 | P1 |
| F3.7 | 根据输入内容推荐模式，只推荐不自动切换 | P2 |

### F7 失败与恢复

| ID | 需求 | 级别 |
| --- | --- | --- |
| F7.1 | 失败不弹窗，保留已输出文字，在结果后用两行说明给出下一步；按用户要做的事分类：超时、断网、服务商限制、安全连接、配置错误、未知 | P0 |
| F7.2 | 配置类错误提示输入 `/operator` 交给 Coding Agent 配置，其他给「重试 ⏎」 | P0 |
| F7.3 | 服务商明确返回长度超限时自动分段（段落 → 句子 → 空白 → 字符），成功的片段不重发，按顺序拼回；对话模式下先裁剪上下文再分段 | P1 |

### F8 配置接口

设置的主要使用者是 agent。配置文件就是接口，命令行只补文件做不到的两件事。

| ID | 需求 | 级别 |
| --- | --- | --- |
| F8.1 | `config.json` 是全部设置的唯一来源：模型、模式、快捷键、我的语言、外语、开机启动、笔记目录；旁边有 `config.schema.json`（JSON Schema），每个字段写清含义、取值、默认值和示例 | P0 |
| F8.2 | 热加载：应用监听配置文件，改完立即生效，不需要重启；进行中的请求不受影响 | P0 |
| F8.3 | 配置不合法时继续沿用上一份合法配置，菜单栏顶部标出错误，指出出错的字段与原因；任何配置内容都不导致崩溃 | P0 |
| F8.5 | `check [<模型名>]`：校验配置，再用每个（或指定的）模型真的请求一次，报告是否可用、耗时和回复；`--verbose` 列出实际请求与响应，Key 在任何输出里都打码；`--json` 给 agent 稳定的结构 | P0 |
| F8.6 | 配置提示词：交给 Coding Agent 的说明，写明配置文件与 schema 的路径、Key 写在 `apiKey`、检查的命令、当前配置摘要（不含 Key）；由 Operator 给出或复制 | P0 |
| F8.7 | 命令行与应用是同一个可执行文件 | P0 |

### F9 Operator

应用没有设置窗口。查看和修改设置在面板里输入 `/operator`（参考 monocode 的 `/operator`）；切换主题不需要模型，另有 `/theme`。

| ID | 需求 | 级别 |
| --- | --- | --- |
| F9.1 | 原文以 `/operator` 开头即进入 Operator：命令变色并扫过一道光，模式标签换成「Operator ×」，执行按钮随之换成 Operator 的配色；发出请求后控制条隐藏，原文与追问行已经说明模式，追问行接替拖动面板，键盘也移到追问行（重新打开面板时同样）；× 或删掉命令即退出，控制条回来；同一会话的追问都留在 Operator | P0 |
| F9.2 | 输入完整的 `/operator` 即显示子菜单，后接一个或多个空格、制表符也显示；继续输入时按主题过滤，不匹配的自然语言请求关闭菜单。裸命令直接按 ⏎ 显示本地帮助，不调用模型；Tab、点击或 ↑↓ 选择后按 ⏎ 执行菜单项，Esc 关闭菜单。帮助说明能做什么和示例；还没有模型时附上交给 Coding Agent 的配置提示词 | P0 |
| F9.3 | 带一句话：交给默认模型，可以查看任何设置（快捷键、默认模型、各模式的模型与完整提示词、权限、版本），也可以修改 `config.json` 里除模型服务以外的一切；发送时结果区升起一阵星星 | P0 |
| F9.4 | 修改直接生效：校验通过才写入，回复末尾列出改前 → 改后；在空的追问框按 ⌘Z 或点「撤销」恢复上一份配置；不合法时不写入并说明原因 | P0 |
| F9.5 | 模型服务（endpoint、format、API Key）不在 Operator 里改：它会复制配置提示词，交给 Coding Agent | P0 |
| F9.6 | Operator 可以打开某项权限的系统设置页 | P1 |
| F9.7 | 系统「减弱动态效果」时不播放光扫与星星 | P0 |
| F9.8 | `/theme` 打开主题列表：输入即过滤，↑↓ 选择时实时预览，⏎ 写入 `theme`；不调用模型。`/operator` 的「theme」一项、控制条上的主题按钮也打开这个列表 | P1 |
| F9.9 | 自定义主题：`config.json` 的 `themes` 里每一项以一套内置主题为 `base`，`colors` 只写要改的颜色（面板角色名：background、text、accent、link、code 等 24 个），边框、次要文字、强调色上的文字等派生色随背景和正文自动重算；`theme` 可以写自定义主题的 id，`/theme` 列表排在最前。Operator 能新建或修改它们：改内置主题时总是新建一套并切换过去，不改内置主题；Operator 的提示词里有颜色名对照、当前主题的全部颜色和所有内置主题的概要。改主题后正文与背景对比度低于 4.5:1 时提醒，不拒绝 | P1 |

### F12 笔记（二期）

笔记是临时记录的草稿纸：打开就写，自动保存，可以有很多张。它不接模型，也不和面板的其他功能联动。

| ID | 需求 | 级别 |

## 四、内置模式

| 模式 | 输入语义 | 提示词要点 | 输出 | 默认模型 |
| --- | --- | --- | --- | --- |
| 翻译 | 材料 | 互译：其他语言 → 我的语言；我的语言 → 外语。原文是终端输出或截图识别的文字时，先去掉框线、控制符号和断行；代码、路径、命令、标识符原样 | 跟随原文：原文是 Markdown 时保留结构，否则纯文本 | 默认 |
| 润色 | 材料 | 保持原文语言，润色用词、语法、语气，不改意思；内容杂乱时（聊天记录、网页或 PDF 复制的文字）整理成标题、列表、表格，不增删事实 | 跟随原文 | 默认 |
| 提示词梳理 | 材料 | 把零散的需求梳理成「背景 / 目标 / 约束 / 验收」结构，不臆造需求，缺的信息列为待确认问题 | Markdown | 强 |
| 问答 | 指令 | 直接回答，先给结论，简短；不确定时说明 | Markdown | 快速 |

输出语言：翻译按上表；润色跟随原文；提示词梳理与问答跟随输入语言。都可以在提示词里改。

## 五、非功能需求

| 类别 | 指标 |
| --- | --- |
| 唤起 | 按下快捷键到面板可见 ≤ 50ms；带入选区时额外等待不超过 200ms（辅助功能 150ms + 复制兜底 50ms） |
| 首字 | 收到第一个 token 到它开始显示，本机开销 ≤ 2 帧 |
| 流式 | 120Hz 屏幕上不掉帧；每个 token 的渲染开销不随回复长度增长；60,000 字的回复仍然流畅 |
| 输入 | 原文栏粘贴 100 万字不卡顿；中文输入法组字期间回车、Esc、Tab 交给输入法 |
| 资源 | 空闲时不跑定时器和刷新回调；常驻内存目标 ≤ 100MB；空闲 CPU 为 0 |
| 体积 | 应用包目标 ≤ 50MB |
| 系统 | macOS 15.2 及以上，Apple Silicon |
| 稳定性 | 网络、权限、系统 API、配置文件的失败都不导致崩溃；任何读取都有超时 |

## 六、不做的事

- 不直接改写其他应用中的选区；润色和翻译都在面板内完成，由用户复制结果。
- 终端清洗与语言判断交给模型；截图按 cida 的识别框恢复同一行、自然折行和段落，保留主动断行与列表。
- 不做听写和语音识别；需要时用第三方输入工具。
- 不做完整的命令行，只有 `check`。
- 不做 MCP 服务或其他常驻的 agent 接口；agent 通过配置文件和这两个命令完成设置。
- 不保存会话历史，不做会话列表和搜索。
- 笔记不接模型：不把面板的结果存成笔记，不对笔记做 AI 改写；不做文件夹、标签和置顶。
- 不做 Windows、Linux 版本；不做公开发布（签名、公证、自动更新）。
- 不内置模型、不做账号体系和云同步。
- 不做文件、图片附件的对话（截图只取文字）。
