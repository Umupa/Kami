# 需求

本文是需求的唯一来源。目标与最终效果见 [vision.md](vision.md)，实现方式见 [architecture.md](architecture.md)。辞达的设计规范（`Xuanwo/cida` 的 `Design/spec/*.md`）是许多细节的参考，本文引用时写作「同辞达 panel.md §一」。

## 一、优先级

| 级别 | 含义 |
| --- | --- |
| **P0** | 替代辞达与核心新场景所必需，缺了就不能日常使用 |
| **P1** | 明显提升体验，紧随 P0 完成 |
| **P2** | 以后再做，或等待定问题有了答案 |

## 二、场景

| # | 场景 | 文字从哪来 | 期望的结果 | 模式 |
| --- | --- | --- | --- | --- |
| S1 | 读外文，翻译一段 | 选区 / 粘贴 | 译文，在面板里读或复制 | 翻译 |
| S2 | 写外文或中文，润色 | 选区 | 原处替换，或在面板里看 | 改进 |
| S3 | 混乱文本，翻译并整理 | 粘贴（聊天记录、网页、PDF 复制出的文字） | 结构清楚的中文 Markdown：标题、列表、表格 | 整理 |
| S4 | 读 Claude Code 的英文输出 | 终端里的选区 | 中文，代码、路径、命令、标识符原样，格式规整 | Agent 转译 |
| S5 | 用中文给 Claude Code 提需求 | 面板里输入或口述 | 写给 Coding Agent 的英文，可直接粘回终端 | Agent 转译 |
| S6 | 把口述的模糊需求梳理成提示词 | 面板里输入或口述 | 结构化提示词（背景、目标、约束、验收） | 提示词梳理 |
| S7 | 快速问一个问题 | 面板里输入 | 简短、准确的回答，可以追问 | 问答 |
| S8 | 读图片、视频字幕、远程桌面里的文字 | 屏幕截图，本机识别 | 识别出的文字进入面板，按默认方式翻译 | 翻译 |
| S9 | 在原处读外文消息和网页 | 指针下的段落 / 整个窗口 | 译文盖在原文位置上，再按换回 | 翻译（原处） |
| S10 | 对任何结果不满意 | 上一轮结果 | 追问调整：「再短一点」「换个语气」「表格加一列」 | 任何模式 |

## 三、功能需求

### F1 面板

| ID | 需求 | 级别 |
| --- | --- | --- |
| F1.1 | 不激活应用的浮动面板：唤起后原应用保持前台，面板拿到键盘；浮在全屏应用之上，跨桌面空间 | P0 |
| F1.2 | 出现在鼠标所在屏幕，水平居中，顶边在可见高度 20%；按下即出现，不淡入 | P0 |
| F1.3 | 宽度固定（800），高度随内容，顶边固定只向下生长，上限为可见高度 70%；高度变化 150ms 过渡 | P0 |
| F1.4 | Esc、再按唤起键、点击面板外、切换应用时隐藏；隐藏不丢状态，进行中的请求继续，下次唤起原样出现 | P0 |
| F1.5 | 结构：原文栏 → 控制条（模式选择、执行按钮）→ 结果区（单轮结果或对话流）→ 追问输入框 | P0 |
| F1.6 | 每次唤起时原文栏拿到焦点，保留光标与选区，不自动全选 | P0 |
| F1.7 | 不允许拖动和改变大小，不提供钉住 | P0 |
| F1.8 | 外观跟随系统浅色 / 深色 | P1 |

### F2 入口

| ID | 需求 | 级别 |
| --- | --- | --- |
| F2.1 | **⌥A 显示 / 隐藏面板**，唤起前读取选区：与上次带入的不同则替换原文，用默认模式立即执行；相同则原样出现（同辞达 panel.md §一） | P0 |
| F2.2 | 读选区先用辅助功能（`kAXSelectedText`，最多 150ms），读不到时模拟一次 ⌘C（最多再等 50ms），剪贴板每一项每一种类型原样放回并标记为临时内容；排除编辑器无选区时的整行复制；密码框、安全输入、前台是自己时不复制 | P0 |
| F2.3 | **⌥F 改进并替换**：选中文字用「改进」模式生成，完成后写回原处，原应用里 ⌘Z 可撤销；生成中再按取消；用户在此期间改了文字、选区或切换应用时不写回，结果留在面板 | P0 |
| F2.4 | **⌥S 截图翻译**：冻结鼠标所在屏幕，框选区域，本机识别文字（简体中文与英文，按行判断语言），按段落规则拼行后带进面板并翻译；没有文字时只提示，不发请求（同辞达 panel.md §一） | P0 |
| F2.5 | **⌥D 原处翻译这一段**：指针下的段落就地盖上译文，等待时段落下垫一层呼吸的底色，再按换回（同辞达 translation-layer.md §二） | P0 |
| F2.6 | **⌥⇧D 整窗翻译**：窗口里所有外文段落换成译文，新内容出现时继续翻译，按应用或网站记住，再按停止（同辞达 translation-layer.md §三） | P0 |
| F2.7 | 原处译文跟随滚动：有屏幕录制权限时实时跟随，没有时滚动停下后重新定位 | P1 |
| F2.8 | 四个全局快捷键都可以在设置里重新录制或清除；开发期默认用 ⌃⌥ 组合，与辞达错开 | P0 |
| F2.9 | 菜单栏图标：显示面板、截图翻译、设置、退出；请求进行中图标有活动状态 | P0 |
| F2.10 | 每个模式可以绑定自己的全局快捷键（例如直接唤起「Agent 转译」） | P2 |

| F3.2 | 内置六个模式：翻译、改进、整理、Agent 转译、提示词梳理、问答（定义见 §四） | P0 |

| F3.4 | 翻译的去处同辞达：其他语言译成「我的语言」；原文是我的语言时译成「翻译成」后面写着的外语，⌘L 就地改写 | P0 |
| F3.5 | 自定义模式：名字、提示词、输入语义、输出格式、默认模型；可以用固定样例预览；拖动排序，第一项是默认模式 | P1 |

## 四、内置模式

| 模式 | 输入语义 | 方向与行为 | 输出 | 默认模型 | 默认去处 |
| --- | --- | --- | --- | --- | --- |
| 翻译 | 材料 | 互译：其他语言 → 我的语言；我的语言 → 写着的外语 | 跟随原文：原文是 Markdown 时保留结构，否则纯文本 | 默认 | 面板 |
| 改进 | 材料 | 保持原文语言，润色用词、语法、语气，不改意思 | 纯文本 | 默认 | 面板；⌥F 时替换选区 |
| 整理 | 材料 | 译成我的语言（已是我的语言则只整理），重组成标题、列表、表格；不增删事实 | Markdown | 强 | 面板 |
| Agent 转译 | 材料（先做终端清洗） | 英文 → 中文，供阅读；中文 → 英文，写成给 Coding Agent 的指令。代码、路径、命令、标识符、错误信息原样 | Markdown | 强 | 面板；中 → 英时复制 |
| 提示词梳理 | 需求 | 把口述或零散的需求梳理成「背景 / 目标 / 约束 / 验收」结构，不臆造需求，缺的信息列为待确认问题 | Markdown | 强 | 面板，复制 |
| 问答 | 指令 | 直接回答，先给结论，简短；不确定时说明 | Markdown | 快速 | 面板（对话） |

输出语言：翻译、整理、Agent 转译按上表；改进跟随原文；提示词梳理与问答跟随输入语言，可在模式里改。

## 五、非功能需求

| 类别 | 指标 |
| --- | --- |
| 唤起 | 按下快捷键到面板可见 ≤ 50ms（无选区带入）；带入选区时额外等待不超过 200ms（辅助功能 150ms + 复制兜底 50ms） |
| 首字 | 收到第一个 token 到它开始显示，本机开销 ≤ 2 帧 |
| 流式 | 120Hz 屏幕上不掉帧；每个 token 的渲染开销不随回复长度增长；60,000 字的回复仍然流畅 |
| 输入 | 原文栏粘贴 100 万字不卡顿；中文输入法组字期间回车、Esc、Tab 交给输入法 |
| 资源 | 空闲时不跑定时器和刷新回调；常驻内存目标 ≤ 100MB；空闲 CPU 为 0 |
| 体积 | 应用包目标 ≤ 50MB（含字体） |
| 系统 | macOS 15 及以上，Apple Silicon；Intel 与通用二进制待公开发布时再定 |
| 隐私 | 见 F11 |
| 稳定性 | 网络、权限、系统 API 的失败都不导致崩溃；任何读取都有超时 |

## 六、不做的事

- 不保存会话历史，不做会话列表和搜索。
- 不做 Windows、Linux 版本（MyGo 支持，但不在范围内）。
- 不内置模型、不做账号体系和云同步。
- 不做浏览器插件；网页里的原处翻译靠辅助功能。
- 不在面板上切换「我的语言」，它属于设置。
- 不做文件、图片附件的对话（截图只取文字）。
