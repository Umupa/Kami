# cida-next

> 代号，正式名称待定。

一个常驻菜单栏的 macOS 原生应用：在任何应用里按一个快捷键，带着选中的文字唤出面板，用你自己的大模型完成翻译、润色、整理、Coding Agent 转译、提示词梳理和快速问答，结果以 Markdown 流式呈现，可以继续追问。

它是 [辞达（Cida）](https://github.com/Xuanwo/cida) 的替代品：保留辞达好用的入口（⌥A 带入选区、⌥F 原处改进、⌥S 截图翻译、⌥D 原处翻译），补上它没有覆盖的场景（Markdown 渲染、多轮对话、多种处理模式、多个模型），用 Go 和 [MyGo](https://github.com/egoist/mygo) 重写。
