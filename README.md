<h1 align="center">Kami</h1>

<p align="center">100% Go · GPU 实时绘制 · 9 MB 安装包 · 流畅体验</p>

<h3 align="center">一个快捷键，把手头的文字交给你的大模型。</h3>

<p align="center">
  <a href="https://umupa.github.io/Kami/">官网与交互演示</a>
  &nbsp;·&nbsp;
  <a href="https://github.com/Umupa/Kami/releases/latest"><b>下载 Kami</b></a>
  &nbsp;·&nbsp;
  <code>brew install --cask umupa/kami/kami</code>
</p>

<p align="center">需要 macOS 15.2 或更新版本</p>

## 功能

<table>
  <tr>
    <td width="33%" valign="top">
      <h3>划词翻译</h3>
      <p>双击 ⌥ 翻译选中文字，支持追问。</p>
      <img src="docs/media/translate.gif" width="240" alt="划词翻译演示">
    </td>
    <td width="33%" valign="top">
      <h3>润色整理</h3>
      <p>润色文字，整理标题、列表和表格。</p>
      <img src="docs/media/improve.gif" width="240" alt="润色整理演示">
    </td>
    <td width="33%" valign="top">
      <h3>随时问答</h3>
      <p>⌥Space 打开面板，随时提问。</p>
      <img src="docs/media/chat.gif" width="240" alt="随时问答演示">
    </td>
  </tr>
  <tr>
    <td width="33%" valign="top">
      <h3>随手记</h3>
      <p>多条笔记，停下就自动保存成 Markdown。</p>
      <img src="docs/media/notes.gif" width="240" alt="随手记演示">
    </td>
    <td width="33%" valign="top">
      <h3>截屏翻译</h3>
      <p>⌥S 框选界面、字幕或图片，识别并翻译。</p>
      <img src="docs/media/capture.gif" width="240" alt="截屏翻译演示">
    </td>
    <td width="33%" valign="top">
      <h3>内置主题</h3>
      <p>18 套配色，<code>/theme</code> 边选边预览。</p>
      <img src="docs/media/themes.gif" width="240" alt="内置主题演示">
    </td>
  </tr>
  <tr>
    <td width="33%" valign="top">
      <h3>自定义模式</h3>
      <p>用 <code>/operator</code> 添加自己的模式。</p>
      <img src="docs/media/custom-mode.gif" width="240" alt="自定义模式演示">
    </td>
    <td width="33%" valign="top">
      <h3>自定义配色</h3>
      <p>基于内置主题调整颜色，⌘Z 随时撤销。</p>
      <img src="docs/media/custom-theme.gif" width="240" alt="自定义配色演示">
    </td>
    <td width="33%" valign="top">
      <h3>配置交给 Agent</h3>
      <p>把提示词交给 Agent，接好自己的模型。</p>
      <img src="docs/media/agent.png" width="240" alt="配置交给 Agent演示">
    </td>
  </tr>
</table>
