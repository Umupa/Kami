# CaskaydiaCove Nerd Font

来源：[Nerd Fonts v3.5.1 / CascadiaCode](https://github.com/ryanoasis/nerd-fonts/tree/v3.5.1/patched-fonts/CascadiaCode)。

保留上游原始 TTF 文件：Regular、Bold、Italic、BoldItalic。上游内部短名为 `CaskaydiaCove NF`，应用注册为 `CaskaydiaCove Nerd Font`。许可证见同目录 `LICENSE`（SIL OFL 1.1）。

这些文件和许可证由 `internal/design/fonts.go` 嵌入可执行文件，不要求用户安装字体。中文和 emoji 等缺失字形由 macOS 补齐。
